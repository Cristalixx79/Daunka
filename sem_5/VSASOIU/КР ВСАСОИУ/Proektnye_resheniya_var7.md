# КР ВС АСОИУ, вариант 7 — проектные решения (этап 1: микропрограмма и структурная схема ОА)

Операции: D (деление), а3 (вычитание обратное), а5 (вычитание модулей обратное), Л1, Л3, Л4, Л6. Разрядность 10, код прямой, серия К500.

## Допущения (проверьте со своими требованиями)

- Слово: бит 9 — знак, биты 8..0 — модуль (прямой код).
- Порядок ввода: 1-е слово → A, 2-е → B; для деления 3-е слово (делитель) → D. Делимое: A = старшая часть (знак + 9 бит модуля), B = младшая (10 бит модуля), т. е. 19 бит модуля.
- Обратное вычитание: а3 = B − A (из второго слова вычитается первое); а5 = |B| − |A|.
- Код операции — Швх(9:7), остальные разряды команды не используются (сдвигов в варианте нет). Коды: D=001 (B1), а3=010 (B2), а5=011 (B3), Л1=100 (B4), Л3=101 (B5), Л4=110 (B6), Л6=111 (B7).
- Деление: метод с восстановлением остатка, 10 итераций; делитель = 0 → ПР:=1, результат не выдаётся (ПР:=0 при начале следующей операции); делимое = 0 → частное и остаток = 0. Выдача: сначала частное, затем остаток (знак остатка = знак делимого, знак частного = XOR знаков).
- Переполнение результата не обрабатывается (частное должно помещаться в 9 бит модуля; для а3 |B−A| ≤ 511).
- В частном/остатке возможен «−0» (при нулевом модуле и знаке «−»).
- АЛУ: Л-операции выполняются прямо функциями АЛУ (К500ИП181), поэтому каждая — одна микрооперация.
- Основная надпись: Выполнил — Дейнеко А.В., Проверил — Спиридонов С.Б. (как в образце), группа ИУ5-55Б.
